## §4 图谱审核（审核台 / 知识图谱页）

- [ ] 审核台「待审图谱」页签能看到本次导入的 draft 节点/关系；搜索可定位
- [ ] 节点逐条/批量「通过」：状态变「已通过」；审核人记录在案（图谱页填写姓名）
- [ ] 节点详情：溯源、依赖规则展示正确
- [ ] 关系审核：两端节点已通过后才能「通过」（用一条两端未审的关系验证被拒绝）
- [ ] 关系方向抽查 10 条：如 DISEASE_HAS_SYMPTOM 的源是疾病、目标是症状
- [ ] 级联失效演练：失效 1 个已通过节点 → 相连关系变「待复核」→ 恢复节点 → 关系保持待复核 → 对关系「通过」恢复
- [ ] 审核台「待复核」「孤儿条目」页签：本次产生的条目清零或逐条确认
- [ ] 拒绝演练：拒绝 1 个错误节点，确认依赖它的规则被阻断（若有）

## §5 规则审核与启用（规则管理页）

- [ ] 新增规则全部出现在规则列表，状态 draft
- [ ] 「图谱语义」列：一致 ＿＿ 条 / 不一致 ＿＿ 条
- [ ] 不一致规则处理：用「补全条件」按图谱补齐无概念条件；补后变一致。实测：＿＿＿
- [ ] 「图谱依赖」列：依赖未通过的用「补审依赖」一键通过；缺失依赖（missing）的记录原因
- [ ] 逐条审核规则内容：条件逻辑符合指南原意（**核心人工环节，逐条记录修改意见**）
- [ ] 启用：依赖全部已通过 + 语义一致 + 质量检查通过 → 启用成功
- [ ] 门禁负例：人工把某依赖改回 draft，确认该规则启用被拒绝并列出阻断项
- [ ] 治疗规则：确认默认 draft、不自动启用
- [ ] 「批量启用一致规则」：只启用符合条件的，跳过原因展示
