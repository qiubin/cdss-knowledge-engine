# 指南解析与审核质量升级

## 已实施

1. 自动解析先抽取临床陈述，再编译为图谱和规则。每条规则绑定陈述编号并继承其原文、人群、分型、阶段和例外。旧格式模型响应只作为待复核候选保留。
2. 不再用第一个片段或整段文字自动补造规则引文，不再截断完整推荐引文。治疗方案按陈述／片段匹配，不按疾病名称直接拼接。
3. 覆盖报告逐片段列出已处理、失败、未安排，保留章节和页码。报告存入知识包和导入元数据。已处理不等于临床知识完整召回。
4. 混合文字／扫描PDF按缺少文字的图像页补OCR；PDF组件可用时保留表格行列和坐标，送入陈述抽取，并提供PDF原页查看入口。复杂表格、流程图和脚注仍须对照原PDF核对。
5. 审核依据与实际保存的指南页行校验，引文须匹配，缺页、倒置、错引和已知不完整解析阻断通过。核验结果会随原文文件变化更新。
6. 审核详情显示原文、临床陈述和问题。人群、分型、阶段、例外、推荐等级、证据等级及待补项可编辑。待补信息未解决时不能通过依据审核。
7. 质量复核队列沿用历史数据，只改变返回的有效状态，不覆盖原审核记录。已启用的依据关联规则在推荐API中执行前会重新核对依据；阻断结果随诊断信息返回。
8. 默认推荐只执行active规则，草稿及testing规则只能在显式test_mode中运行。页面有候选测试开关及结果标识，原生和Drools共用此边界。

## 操作

导入后查看覆盖报告；审核台进入诊疗依据审核，勾选“仅显示有问题的依据”。打开详情，对照实际原文核对陈述；编辑补全后移除已解决的待补项，确认适用范围，再完成依据审核和规则审核。

旧导入没有覆盖报告时不推定完整，也不自动重新调用模型。旧出处无效时需修复定位或重新解析。此次升级没有自动改写本地已审核的医学结论。

## 验证边界

出处匹配是文字校验，不能证明医学含义正确。程序回归测试采用隔离样例，不能据此宣称医学准确率。真实指南的专家标注集、审核耗时、遗漏率和关键错误漏检率需要由医学知识专员持续建立；表格／流程图结构恢复和多指南冲突消解尚未全面自动化。
