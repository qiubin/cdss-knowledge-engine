# 心肌病场景改造执行计划

更新日期：2026-11-25。

## 范围与原则

优先成人 HCM，复用指南抽取、图谱审核、诊疗依据审核、规则审核及现有三态推理。既有启用规则的迁移必须单独核对，不自动重新发布临床知识。本计划区分代码具备、病例验证与临床上线，三者不能互相替代。

## 现状核查

- 场景工作台当前有疑似、确诊／分型、治疗方案、用药决策四类入口。
- clinical_intent 已包括鉴别、排除、风险、监测、随访；有用途编码不代表对应场景完整实现。
- 引擎已有 unknown 传播、COUNT 缺失处理和 evaluation_issues。
- HCM 已有壁厚、静息／激发压差模板与边界测试；模板默认草稿。
- 医嘱组和路径实体、order_set_ids 已有；仍需独立核对物化、院内映射和反馈服务。
- PatientSnapshot 有时间字段，但不等同于纵向病程及家系管理服务。

## P0 病例验收集

1. 典型且资料完整：判断和来源可核对。
2. 表型相似、病因不同：输出鉴别，不直接确诊。
3. 缺关键资料：输出未知和待补项，不以未记录当作阴性。
4. 单位、方法、状态或时间冲突：提示复核，不错误套用标准。
5. 有治疗候选且存在禁忌：输出限制及理由。
6. 已有明确诊断：使用有效诊断进入适当管理分支。

每类病例需有输入、预期结论、禁止出现的结论、依据和版本；代码回归通过后，再进行专家审阅和静默验证。
