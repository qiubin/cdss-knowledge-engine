# 检查与检验判定标准

标准管理的上方显示规则和待审诊疗依据需要的判定，下方维护当前医院的实际配置。上方包含图谱证据、直接条件及必要子条件，可按检查或检验筛选。覆盖状态表示配置准备程度，不代表医学内容已经审核。

检查标准用“检查项目编码 + 检查发现编码 + 判定概念”定位，支持：

- 数值比较：比较方式、阈值或上下界、单位。
- 分级或定性：列出满足该概念的结构化结果值，精确匹配。
- 存在性：使用明确的存在或不存在结果。

可限定性别、年龄、检查方法及有效日期。保存为草稿，校验并启用后参与执行；修改已启用配置会返回草稿。旧检验数据默认仍属于检验，无须批量迁移。

已经结构化为存在或不存在的检查发现，可以在没有医院标准时直接参与存在性判断。规则也可设置“必须使用判定标准”。一旦该检查发现已配置医院标准，未启用、失效或不适用于患者的配置不会退回直接判定。

病例测试支持录入检查测量值、单位、分级、方法及报告原文。原文仅供查阅，不自动转换为阳性。缺少所需结果、缺少标准或单位不一致时，检查条件为无法判断；普通 AND、OR、NOT 组合保留该状态，不能用 NOT 将未知变成满足。加权条件仍按已确认满足的证据计分，无法判断项另列诊断提示。

指南明确的检查判定参数可保存在条件或证据的 `parameter.interpretation` 中，优先于医院标准。医院参考范围不应替换指南的明确诊断界值。系统没有自动添加或启用未经确认的临床检查阈值；配置内容须填写来源并经业务审核。

当前不提供自由报告文本判读或单位换算。数值结果需采用标准对应的单位；分级结果需采用配置中的编码或值。
