# 疾病场景审核工作台

审核台默认进入疾病审核工作台。选择图谱与疾病，先核对疾病和关联实体，再审核关系，最后在场景区整理诊疗依据。

## 场景

- 疑似诊断
- 确诊／分型
- 治疗方案
- 用药决策

已有依据按 clinical_intent 展示，不改变旧审核状态。整理新依据时，勾选已审关联、选择判断条件或建议项目、确认且／或关系，再从关联引用中读取指南原文。核对人填写适用范围，系统生成候选依据并打开审核详情。确认依据后生成草稿，进入规则审核。

仅检查／检验项目不能直接编成阳性条件，须选择对应发现或抽象检验概念。治疗项目进入结论。单层条件可直接整理，复杂嵌套、人群限制和禁忌可在条件编辑器中完善。禁忌和监测仍通过原有规则编辑器单独维护；场景表暂不把这两种关联自动编译。

新场景治疗规则明确保存 diagnosis_prerequisite，默认 confirmed。只有同疾病、临床用途为确诊判断的诊断结论命中，才能评估治疗；选择 suspected 时也接受疑似诊断结论。新场景治疗草稿不会执行，须审核启用。旧规则保持原有执行兼容性。

每份场景依据记录选择的关系、用途、图谱内容指纹、原文、范围说明和核对人。关联未通过、内容变化、缺失或跨指南引用将阻断生成。重复提交同一份整理内容复用原依据。

现有已审图谱无需重新导入。多指南的数据不自动合并成一条临床规则，按当前所选指南整理；复杂的分型及医院标准映射仍需依据原文核对。
